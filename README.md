# ZMM Room App — starter PWA

This is the visual and installable-PWA foundation only. It does not yet contain authentication, a database, receipt upload, OCR, expense approval APIs, or real financial data. Do not enter private information in this starter.

## Files
- `index.html` — mobile-friendly starter screen
- `manifest.webmanifest` — installable app metadata
- `sw.js` — basic offline caching for the app shell
- `icon.svg` — app icon

## Next stage
Connect a secure backend and private object storage, implement phone/password registration and approval, persistent sessions, receipt upload, expense workflows, and admin-only record changes. Keep all secrets out of this repository.
